### Legenda (feed / carrossel)

**Construí um e-commerce full-stack do zero — e o pagamento funciona de verdade (em sandbox). 🛒➡️✅**

O **TechStore** é meu projeto de portfólio: catálogo, carrinho, login com JWT, checkout e pagamento via **Mercado Pago**, tudo no ar.

O fluxo completo roda de ponta a ponta:
🛍️ você navega e monta o carrinho
💳 o checkout cria a preferência no Mercado Pago
🔐 um **webhook assinado (HMAC-SHA256)** confirma o pagamento
✅ o pedido vira **PAGO** e o estoque atualiza sozinho

**Stack:**
⚙️ Java 17 + Spring Boot 3 · Spring Security (JWT) · JPA
🐘 PostgreSQL versionado com **13 migrations Flyway**
🎨 Frontend em HTML/CSS/JS puro, sem framework e sem build
🚀 Deploy automático: push na `main` → Netlify + Render

**Como trabalhei:** desenvolvi usando **LLMs como assistência** e **SDD (Spec-Driven Development)** — especificações claras primeiro, IA para acelerar código, revisão e debug. Arquitetura, requisitos e validação foram meus; a IA entrou como par técnico. Conduzir IA com critério é hoje uma competência central de engenharia, e preferi mostrar isso abertamente.

**Transparência:** projeto de estudo/portfólio em **sandbox** do Mercado Pago — nenhuma cobrança real, não é sistema em produção.
